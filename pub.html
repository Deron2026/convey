摘要

Ornith-1.0是一个能自我改进的开源编程AI模型，由团队基于Gemma 4和Qwen 3.5打造，提供9B、31B、35B和397B四种大小版本。它在Terminal-Bench 2.1、SWE-Bench等编程测试中表现顶尖，比如9B版在SWE-bench Verified上达到69.4%，远超同类模型。对你的好处是：它能自动生成代码并优化搜索路径，帮你省去手动调试的繁琐步骤，尤其适合写脚本、修bug或搭建项目。上手超简单：模型采用MIT开源协议，全球免费使用，你只需在Hugging Face下载或通过API调用，就能直接体验。推荐场景：1）内容创作者快速生成自动化工具（如批量处理文件）；2）开发者用AI辅助写复杂代码或修复错误；3）日常用户尝试用自然语言描述需求，让AI帮你写简单脚本。

深度分析

快速上手路径：5分钟跑通第一个对话

不用纠结环境配置，直接复制新闻里的 Transformers Python 脚本就能立刻体验 Ornith-1.0。

第一步： 装好 transformers>=5.8.1 和 PyTorch（建议用 pip 安装最新版）。

第二步： 把新闻中的加载代码粘贴到你的笔记本或 .py 文件中，模型名换成 deepreinforce-ai/Ornith-1.0-9B（9B 模型，单张 80GB GPU 即可运行）。

第三步： 运行上一条消息示例，比如 "Write a Python function is_prime(n). Keep it short."，几秒后就会看到带 思考块和最终答案的输出。

立刻行动点：复制新闻中的 from transformers import AutoModelForCausalLM, AutoTokenizer 代码块，改一下提示词，你就能立刻得到一个会“思考”的编程助手。注意一定要用 temperature=0.6, topp=0.95, topk=20 这些推荐采样参数。如果显存不够，还可以用 GGUF 量化版本配合 Ollama / llama.cpp 本地运行。

与常见工具的直观对比：开源模型也能打

从新闻的 SWE-bench Verified 看，Ornith-1.0-9B 得分 69.4，而同尺寸的 Qwen3.5-9B 只有 53.2，差距超过 16 个百分点。

在更大尺寸上，Ornith-1.0-397B 的 Terminal-Bench 2.1 (Terminus-2) 得分 77.5，远超 Qwen3.5-397B 的 53.5，甚至超过 DeepSeek-V4-Pro 的 64，只略低于 Claude Opus 4.8 的 85。——但它是MIT 开源、免费、无地域限制，而 Claude 是闭源收费服务。

立刻行动点：如果你平时用 GPT-4 / Claude 写代码，对比一下 SWE-bench Pro 分数：Ornith-1.0-397B 得 62.2，Claude Opus 4.8 是 69.2；而更小的 35B 版也有 50.4。对于只需本地部署或不想付费的场景，这个性能性价比极高。

新手最容易遇到的问题与解决办法：版本不兼容是最大坑

新闻专门强调了运行前提：Transformers ≥ 5.8.1、vLLM ≥ 0.19.1、SGLang ≥ 0.5.9。新手如果用较旧的 pip 包，会直接报错或出现奇怪的行为。

解决办法：启动前先执行 pip install --upgrade transformers vllm sglang 强制升级到最新。

另一个容易忽视的点是 工具调用（tool-call） 格式：新闻说服务端要配 --tool-call-parser qwen3xml 和 --reasoning-parser qwen3。新手如果直接用 vLLM 默认配置，模型会返回原始 XML 而非标准的 toolcalls 字段。

立刻行动点：如果你使用 vLLM，务必加上 --enable-auto-tool-choice --tool-call-parser qwen3xml --reasoning-parser qwen3 这三行参数。对于 SGLang，则用 --tool-call-parser qwen3coder。否则功能不完整。

问题根源：当你的验证器是二元（0/1），且模型初始完全随机时，同一个prompt生成的10个rollout可能全部得0分。GRPO会将组内奖励减去均值（0），所有优势变成0，梯度消失——你白白浪费了10次推理的计算资源。

BV-Blend的解法：它不只看当前组，还看历史同类prompt的奖励分布。即使当前组全0，如果历史同类prompt的平均正确率是15%，那么当前组的优势就不是0，而是 0 - blended_mean（负值），从而产生有效梯度，推动模型向更高概率移动。

新手避坑指南：

  • 不要手动设置每个cluster的初始均值，让EMA从0开始自然积累
  • 选择合理的cluster数量：太少（<5）会让历史数据太嘈杂；太多（>50）会导致每个cluster数据稀疏。建议10~20个。
  • 如果发现训练初期优势震荡过大，调大SEM权重公式中的分母常数（比如从1改为2），使历史影响更保守。
