摘要

谷歌DeepMind今天发布了DiffusionGemma，一个能并行生成256个词的实验性开源模型，NVIDIA还专门优化了它在RTX显卡上的运行速度，本地PC就能跑，速度提升最高4倍。简单说，它不像传统AI那样一个字一个字“挤牙膏”，而是像画画一样整段整段“刷”出来，写文章、改文案、做代码注释时几乎感觉不到延迟。

对你的好处：如果你是内容创作者，用它写博客、生成营销文案，省掉等待时间，灵感不会断；开发者调试代码时，它能快速生成多行注释或文档，效率翻倍；日常用户想快速总结长文章、写邮件，本地运行免费无限制，不用联网付费。上手超简单：模型已开源，Apache 2.0协议，在Hugging Face上直接下载，配合vLLM或Unsloth工具，一行代码就能跑起来。推荐场景：1）写作辅助：快速生成段落草稿；2）代码注释：批量生成函数说明；3）本地AI助手：离线聊天、翻译。

深度分析

快速上手路径：5分钟跑通本地文本生成

想立刻体验DiffusionGemma的速度？最直接的方式是通过Hugging Face Transformers，在GeForce RTX 5090或DGX Spark上开箱即用。你只需加载模型并传入提示词，无需云端、无需配置。比如运行以下Python代码（已在支持的GPU上测试）：

`python

from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("google/diffusion-gemma-4-26b")

tokenizer = AutoTokenizer.from_pretrained("google/diffusion-gemma-4-26b")

inputs = tokenizer("Explain quantum computing in one sentence.", return_tensors="pt")

outputs = model.generate(**inputs, maxnewtokens=256)

print(tokenizer.decode(outputs[0]))

`

立刻行动点：今天就在本地RTX GPU上运行上述代码，直接感受并行生成256 tokens的流畅响应，无需等待单字输出。

相比传统逐字生成的自回归模型，DiffusionGemma通过并行去噪一次输出最多256个tokens，将单用户场景下的文本生成速度提升至4倍。新闻数据表明，在NVIDIA H100上达到1000 tokens/s，在DGX Spark上达到150 tokens/s。这意味着原来需要10秒的响应，现在约2.5秒完成。对于开发者调试Agent循环或交互式聊天，每次都能省下75%的等待时间。立刻行动点：在你的本地工作流中用DiffusionGemma替换现有逐字模型，测试一个多轮对话任务，记录前后耗时对比。

典型使用场景举例：本地开发、Agent和聊天场景

新闻强调的典型场景包括：

1. 交互式聊天：作为本地运行的AI助手，响应速度快到感觉像真人对话，适合日常问答或头脑风暴。

2. Agent循环：开发者可构建自主规划的Agent，模型在每个决策步骤中快速生成计划文本，加速推理链。

3. 本地原型开发：研究人员在DGX Spark上微调模型，使用Unsloth或NVIDIA NeMo快速针对特定任务适配，无需云成本。

4. 内容创作者：生成博客、代码注释或大纲时，块级输出让首次草案几乎瞬间完成。

立刻行动点：今天就用Hugging Face的示例代码运行一个生成20条营销文案的任务，比较与ChatGPT的端到端耗时差异。
