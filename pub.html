1.2.1 安卓手机存储被AI吃光？谷歌终于承认：这是为了让你更省心

↑ 返回目录

摘要

谷歌终于解释了安卓AICore疯狂占存储的原因——主旨是：当Gemini Nano新版本更新时，手机会同时保留新旧两个版本最多3天，以防新模型出问题后能秒回旧版，避免你重新下载几GB数据。关键数据/特点是：这个“双版本缓冲”机制虽然会临时多占几GB空间，但能省去你断网或重装时的漫长等待。对你的好处是：你手机上的AI功能（如WhatsApp智能回复、短信诈骗检测、实时语音转文字、语法修正、音频摘要）都靠它本地运行，数据不出手机、不用联网、零延迟，隐私和速度双赢。快速上手方式：只需在安卓14以上设备中，进入“设置-存储”查看AICore占用，若发现异常大，等3天系统会自动清理旧版本。推荐场景：适合内容创作者（离线语音转文字写稿）、日常用户（飞行模式下用AI回复消息）、开发者（本地测试AI功能无需云端依赖）。简单说：多占几天存储，换你永远不掉线的AI体验，值了。

深度分析

快速上手路径：理解并管理AICore存储

如果你想查看AICore的存储占用，打开手机设置 > 存储，找到AICore或系统应用下的相关条目。新闻提到，当Gemini Nano模型更新时，旧版本会保留最多3天作为安全回退。如果你着急释放空间，可以手动检查是否有旧版本残留：进入应用管理，搜索AICore，点击清除数据（注意：这会重置所有离线AI功能，需重新下载最新模型）。立刻行动点：下次更新后等2天再检查存储，通常会自动恢复到正常大小。

典型使用场景举例：离线AI功能的实际应用

新闻明确列出了几个场景，你立刻就能用到：

  • 智能回复：在WhatsApp等聊天应用中，收到消息时键盘上方会弹出建议回复，点击即可发送，无需网络。
  • 诈骗检测：在短信应用中，系统会实时分析可疑链接和内容，标记潜在诈骗。立刻行动点：打开设置搜索“诈骗检测”，确保已开启。
  • 语音转录与摘要：在录音或会议记录时，AICore能实时转写并生成摘要，支持离线处理。
  • 语法纠正：在任意输入框打字时，系统自动修正语法错误。这些功能都依赖Gemini Nano本地运行，数据不出手机。

新手最容易遇到的问题与解决办法：存储暴增的原因与应对

最常遇到的问题就是AICore占用存储突然变大，比如从几百MB跳到几个GB。解释很简单：Gemini Nano更新时，新旧两个版本并存最多3天，这是安全回退机制。你可能会困惑“为什么不用云备份模型”？实际是本地AI的隐私/离线优势值得牺牲一点空间。解决办法：1. 耐心等待2-3天，存储会自动释放。2. 如果急需空间，可进入应用管理 > AICore > 存储管理，强制终止后台进程并清除缓存（不要轻易点“清除数据”，否则会丢失已下载的模型）。立刻行动点：下次发现存储异常时，先查看AICore版本号，对比官方更新日志确认是否在过渡期。

今天就能完成的探索

  • 1：打开手机设置 > 存储，查看AICore占用的空间大小，并截图记录以便后续对比。
  • 2：在WhatsApp或短信应用中，尝试发送一条消息，观察键盘上方是否有智能回复建议（如有说明AICore已正常工作）。

深度分析

快速上手路径：3条命令即刻拥有AI宠物

在 Codex 应用 里召唤或消除宠物的门槛极低。你只需在输入框键入 /pet 就能立刻出现或隐藏宠物，首条命令就能看到效果。若想挑选外观，直接用 /pet+方向键 在8个预设宠物间切换，无需任何配置。想让宠物更个性化？用 /hatch 命令即可生成专属宠物，比如新闻里提到的“可爱哥布林”。注意：宠物本身不参与编程，但作为浮动层能实时显示 Codex 的活跃任务、完成通知或需你输入的状态。立刻行动点：打开Codex，先输入 /pet 召唤默认宠物，再按方向键换一个顺眼的，全程不到10秒。

典型使用场景举例：开发者边编码边获知状态

对 内容创作者或开发者 来说，宠物是低干扰的状态指示器。

场景2：当你提交代码后等待CI/CD，让Codex帮你处理一个小脚本，宠物会显示当前“忙碌中”状态，你无需打断当前工作流。

新手最容易遇到的问题与解决办法：/hatch生成失败可参考社区

新手最可能卡在两点：

问题1：输入 /hatch 后没反应或生成结果不满意。新闻指出早期用户已上传了大量现成宠物，你可以通过浏览 社区分享的宠物代码 来一键借用（比如Reddit或GitHub上的Codex宠物合集）。解决办法：先复制别人生成成功的 /hatch 参数（通常是描述性文字），粘贴后即出同款。

问题2：宠物遮挡代码区域。用 /pet 可随时关闭，或调整浮动层透明度（新闻未提设置，但通常右键宠物有选项）。立刻行动点：若觉得宠物太大，在代码里输入 /pet 隐藏，改小后再 /pet 唤出。另外，试用期内选出最爱的10个生成宠物，有机会获得 30天ChatGPT Pro，别忘了在设置里提交。

摘要

苹果的SHARP模型现在可以直接在浏览器里运行了！这个开源项目让你上传一张图片，就能在浏览器中生成3D高斯点云，并下载为.ply文件。关键数据：模型文件约2.4GB，需要现代浏览器（推荐Chrome或Edge）和Bun环境。对你的好处：省去了配置复杂GPU环境的麻烦，完全在本地浏览器运行，保护隐私；适合3D内容创作者快速生成预览、开发者学习3D生成技术、普通用户体验AI黑科技。快速上手方式：只需安装Bun，运行bun install和bun dev，打开本地链接即可上传图片生成。推荐场景：快速制作3D模型预览、教学演示、创意设计原型。注意：模型权重有研究用途限制，商用需确认许可证。

深度分析

快速上手路径：4步搞定浏览器内3D生成

你只需要 Bun 和一台现代浏览器。首先克隆仓库 git clone ...，然后执行 bun install 自动下载依赖和ONNX Runtime Web的WASM文件。接着运行 bun dev 启动开发服务器，在浏览器中打开显示的URL（通常是 http://localhost:5173）。上传一张图片，点击 Generate Splat，稍等片刻就能预览并下载 .ply 文件。注意：首次运行需要加载约 2.4GB 的ONNX模型文件（默认使用托管的模型），所以第一次启动会稍慢。

立刻行动点：检查你的电脑是否已安装Bun（bun --version），如果没装，去 bun.sh 一键安装，整个过程不到5分钟。

实际能省的时间与步骤：跳过CUDA和大型Python环境

传统的3D高斯泼溅生成（比如原始SHARP）需要你配置Python环境、安装PyTorch和CUDA，导出ONNX模型往往还要手动处理大型权重文件，整套流程至少耗时 30-60分钟（如果环境不兼容可能更久）。而这个项目让你在浏览器内完成全部流程：上传一张图片 → 点击按钮 → 得到3D结果，省去了 本地依赖安装、GPU驱动调试、模型文件导出 这三个主要痛点。即使你第一次运行需要等待模型初始化和WebGPU编译，整体时间也远小于传统方案。

立刻行动点：现在就可以找一个你电脑上的普通照片（比如手机拍的JPG），直接上传测试，体验从图片到3D的即时转换。

典型使用场景举例：设计师、开发者、3D爱好者的快速原型工具

场景1：内容创作者 你拍了一张产品实物照片，想快速生成一个三维预览用于社交媒体或网站展示。只需上传照片，点击生成，下载 .ply 文件后即可用支持该格式的3D查看器（如Three.js）嵌入网页。

场景2：开发者 你要测试ONNX Runtime Web在浏览器端的推理能力，这个项目本身就是完整的参考实现：包括React+TypeScript前端、Web Worker推理管线、以及PLY文件生成逻辑。你可以直接fork仓库，修改模型或UI来验证自己的优化思路。

场景3：3D爱好者 你想体验苹果最新的SHARP算法，但不想配置庞大的科研代码环境。该项目提供了开箱即用的浏览器版，你只需关注结果，无需关心底层实现。

立刻行动点：如果你是开发者，可以在 src/workers/sharpWorker.ts 中查看推理逻辑，看看Web Worker如何加载模型和运行ONNX Runtime。

今天就能完成的探索

  • 1：安装Bun（若未安装）并克隆仓库：git clone https://github.com/bring-shrubbery/ml-sharp-web.git && cd ml-sharp-web
  • 2：运行 bun install && bun dev，等待启动后打开浏览器 http://localhost:5173，上传一张图片并点击“Generate Splat”按钮体验生成。

摘要

这篇新闻讲的是作者把Gemini集成到Gmail后，彻底改变了处理邮件的体验。以前收件箱里全是会议邀请、营销邮件和重要通知，让人头大，甚至不敢打开。现在Gemini成了“安全网”，能自动提取关键信息，比如高亮重要日期、标记保密时间、抓出需要你注意的细节，再也不用逐字读长邮件了。对你的好处是：省去手动筛选的麻烦，避免错过重要内容，还能把邮件里的会议一键转成日历提醒，每天至少省下30分钟。上手超简单：在Gmail设置里启用Gemini，然后对任意邮件问“总结重点”或“提取关键日期”，它就会给出清晰要点。推荐场景：内容创作者处理PR邮件和合作邀约时快速抓重点；日常用户管理订阅和账单通知；开发者跟进项目更新和会议安排。

深度分析

快速上手路径：三步激活Gemini的邮箱超能力
