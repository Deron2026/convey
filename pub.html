1.4.1 AWS MCP服务器正式上线，AI编程助手秒变“云服务管家”，省时又安全！

↑ 返回目录

摘要

AWS最近正式发布了MCP服务器，让AI编程助手能安全、可控地调用AWS所有API、文档和操作流程。简单说，你的AI助手现在能像“云服务管家”一样，帮你自动完成云资源管理任务，而不用你手动操作或担心权限泄露。

对你的好处：以前用AI操作AWS，要么权限太大不安全，要么文档过时出错多。现在MCP服务器通过IAM权限控制和CloudWatch日志，让AI干活更安全、可审计，省去你反复调试和查文档的时间。它还支持沙盒Python执行，AI能自动完成多步骤任务（比如部署、上传文件），不用你写一行代码。推荐场景：1）内容创作者：自动备份网站文件到S3；2）开发者：用Claude Code或Cursor一键部署应用；3）日常用户：让AI帮你管理云存储、生成报告。快速上手方式：只需在Claude Code中运行一条命令（如claude mcp add-json aws-mcp），就能连接MCP服务器，免费试用。

深度分析

快速上手路径：一条命令连接Claude Code与AWS MCP

你只需要一条命令就能让你的AI编码代理（比如Claude Code）安全地操作AWS服务。新闻中给出的示例命令可以直接复制使用：

claude mcp add-json aws-mcp --scope user '{"command":"uvx","args":["mcp-proxy-for-aws@latest","https://aws-mcp.us-east-1.api.aws/mcp","--metadata","AWS_REGION=us-west-2"]}'

这个命令做了三件事：

1. 通过uvx运行官方代理mcp-proxy-for-aws

2. 连接到AWS MCP服务器的公开端点（目前仅支持北弗吉尼亚或法兰克福区域）

3. 自动处理IAM认证转换为OAuth 2.1

运行后，你的AI代理就能通过标准MCP协议调用所有AWS API，并且遵守IAM权限限制。整个设置不收费（仅资源消耗付费），5分钟内就能完成。

立刻行动点：确保本地安装了uvx（Python包管理工具），然后直接运行上面的命令；如果你的账号在非支持区域，先切换到us-east-1或eu-central-1再尝试。

典型使用场景举例：AI代理自动化AWS日常运维

新闻中提到，AI代理过去因训练数据过时而无法使用S3 Vectors、Aurora DSQL等新服务，现在通过MCP服务器可以获取最新文档和认证API。以下是2个你能立刻尝试的场景：

场景1：自动化S3存储桶管理

让Claude Code读取你账号下的S3存储桶列表，并创建新的存储桶并配置生命周期策略。代理会通过MCP调用S3 API，并通过CloudTrail记录每一步操作。你只需要用自然语言提出需求，比如“列出所有未加密的S3存储桶，并开启默认加密”。

场景2：部署沙箱Python脚本

新闻强调沙箱执行允许代理运行Python代码来完成复杂任务（如多步骤数据转换），但无法访问本地文件系统。你可以让代理编写并测试一个Lambda部署脚本，利用最新文档避免过时API用法。

立刻行动点：在Claude Code中尝试简单指令：“使用AWS SDK列出我当前区域的EC2实例名称和状态”，代理会自动通过MCP获取结果，无需手动配置凭证。

今天就能完成的探索

  • 1：打开终端，运行 claude mcp add-json aws-mcp --scope user '{"command":"uvx","args":["mcp-proxy-for-aws@latest","https://aws-mcp.us-east-1.api.aws/mcp","--metadata","AWS_REGION=us-west-2"]}' 将Claude Code连接到AWS MCP服务器
  • 2：在Claude Code中输入指令“列出我AWS账号下所有S3存储桶的名称和创建时间”，观察代理如何通过MCP安全地调用真实API并返回结构化结果
