1.2.2 **在浏览器里安全跑Python代码？这个新工具让你随便玩不怕崩**

↑ 返回目录

摘要

开发者Simon Willison发布了一个叫micropython-wasm的alpha包，能把Python代码放进沙箱里安全运行，就像给代码套了个“防爆罩”。主旨是让普通用户也能在应用里执行自定义脚本，而不用担心搞坏系统或泄露数据。关键数据/特点是它基于MicroPython和WASM（WebAssembly），代码在隔离环境运行，无法访问本地文件或网络，对你的好处是：你可以放心地在Datasette这类工具里写脚本处理数据、定时抓取JSON并自动存入数据库，或者给表格做批量转换，省时又安全。快速上手方式：安装datasette-agent-micropython插件，然后在Datasette界面里直接写Python代码即可。推荐场景：内容创作者用脚本自动整理数据表格；开发者在插件里安全测试自定义逻辑；日常用户在办公软件里写简单脚本处理重复任务，比如把CSV转成SQLite数据库。

深度分析

快速上手路径：从安装到运行只需两步

想立刻体验micropython-wasm？最简方式是用uvx直接运行，无需安装。打开终端执行：

uvx micropython-wasm -c 'print("Hello world")'

这会在沙箱中执行Python代码，输出Hello world。

如果系统有Python，也可以pip install micropython-wasm后从代码调用：

`python

from micropython_wasm import MicroPythonSession

with MicroPythonSession() as session:

print(session.run("x=10\nprint(x)").stdout)

`

立刻行动点：复制上面的uvx命令粘贴到终端，回车即可验证沙箱是否正常工作。

若想玩更复杂的持久化状态，作者提供了Datasette Agent集成示例：运行uvx --with datasette-agent --with datasette-agent-micropython datasette --internal internal.db --root -o，浏览器打开后输入提示词“show me some micropython”即可在界面中交互运行。

典型使用场景举例：安全运行不可信代码的三大场景

作者在新闻中明确给出了三个实用场景：

1. 插件系统扩展：Datasette、LLM等工具支持插件，但现有插件有完整系统权限。micropython-wasm能安全运行第三方插件代码，限制文件/网络访问，防止恶意插件破坏应用或泄露数据。

2. 数据转换（Enrichments）：对数据库表中的值进行自定义转换，例如用用户提供的Python代码清洗或格式化字段，同时保证不影响核心数据。

3. 定时任务+数据管道：从指定URL抓取JSON，用沙箱内代码重组成字典列表，自动插入SQLite表。代码只能通过暴露的主机函数与外部交互，全程受控。

立刻行动点：如果你有需要用户写自定义逻辑的应用场景（如报告生成、数据预处理），考虑用micropython-wasm替换直接执行用户输入，将安全风险降到最低。

新手最容易遇到的问题与解决办法：注意CPU燃料值和持久化陷阱

新闻提到两个常见坑：

1. CPU限制的“燃料”值设置：作者默认用2000万燃料单位，但“很难合理确定”。如果代码执行时提示“guest exited with code 1”且无其他错误，多半是燃料耗尽。解决办法：降低代码复杂度或增加燃料限额（可在底层wasmtime配置中调整）。

2. 持久化状态依赖线程：MicroPythonSession通过后台线程和队列保持变量，但如使用不当可能导致状态混乱。新闻提到“最棘手的问题就是持久化解释器状态”，因为WASM默认每次调用都重启解释器。解决办法：始终使用session.run()连续执行代码块，不要在每次请求后重新创建session。

立刻行动点：测试时先用简单语句（如x=1）确认状态保持正常，再用循环逻辑测试燃料阈值。若遇到意外退出，检查燃料值并增加参数。
